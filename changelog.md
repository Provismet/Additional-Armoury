Minor update to make the mod work in 1.21.4; this update is focused purely on compatibility, but adds data-related features to achieve it.

## Additions
- Added new tint source to control staff colours. `additional-armoury:spell`
- Added new tint source to control dagger tips. `additional-armoury:dagger`
  - This source is functionally identical to the vanilla potion source, but will make the tip fully transparent if there is no potion. 

## Changes
- Updated to 1.21.4 Minecraft.
